# draw_graph

A desktop app for drawing graphs - learning paths, mind maps, flowcharts and
concept maps - saved as one plain-text [recfile](https://www.gnu.org/software/recutils/).
Keyboard first, vim keys, works offline on macOS, Linux and Windows.

Status: planned, no code yet. The spec is [PLAN.md](PLAN.md); a sample
document is [draw_graph_example.rec](example/draw_graph_example.rec).

## Programs

| Program | Does |
|---|---|
| `draw_graph` | The app: draw and edit a recfile as a graph |
| `draw_graph check FILE.rec` | Headless: print the file's problems, exit 1 on any |
